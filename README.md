# 📚 English Flashcards Pro

![Version](https://img.shields.io/badge/version-2.0-purple)
![License](https://img.shields.io/badge/license-MIT-green)
![Technologies](https://img.shields.io/badge/tech-HTML5%20%7C%20Tailwind%20%7C%20JS-blue)

> Application web interactive pour apprendre l'anglais avec des flashcards, quiz, et suivi de progression.

## ✨ Fonctionnalités

- 📝 **Flashcards interactives** avec animation 3D flip
- 🎯 **Quiz de traduction** intelligent (10 questions aléatoires)
- 📊 **Statistiques détaillées** (score, série, niveau)
- 📖 **Dictionnaire complet** avec recherche
- 💾 **Sauvegarde automatique** (localStorage)
- 🎨 **Design glassmorphism** avec effets visuels
- ⌨️ **Raccourcis clavier** pour navigation rapide
- 📱 **Responsive design** (mobile, tablette, desktop)
- 🌟 **Animations et particules** pour une expérience immersive

## 🛠️ Technologies

| Technologie | Usage |
|-------------|-------|
| **HTML5** | Structure sémantique |
| **Tailwind CSS** | Framework CSS utilitaire |
| **JavaScript (ES6+)** | Logique applicative |
