## 🎯 Pourquoi English Flashcards Pro ?

> *"La méthode la plus efficace pour apprendre une langue n'est pas de mémoriser des règles de grammaire, mais d'enrichir votre vocabulaire, un mot à la fois."*

**English Flashcards Pro** est une application **PWA (Progressive Web App)** complète qui vous accompagne de **débutant à expert** en anglais :

- 🎓 **Étudiant** : préparez vos examens
- 💼 **Professionnel** : évoluez dans votre carrière
- ✈️ **Voyageur** : communiquez à l'étranger
- 🌍 **Passionné** : enrichissez votre culture

## ✨ Fonctionnalités Principales

### 📝 Flashcards Intelligentes
- ✨ **Animation 3D fluide** au clic
- 🎯 **Navigation intuitive** : Précédent · Suivant · Retourner
- ✅ **Marquage "Je sais !"** avec suivi de progression
- 📊 **Barre de progression** visuelle
- 📂 **27+ catégories thématiques**
- 🌓 **Mode clair & sombre**
- 📱 **100% Responsive**

### 🎯 Quiz Interactif
- 🎲 **10 questions aléatoires** par session
- 🔥 **Système de série (streak)** pour rester motivé
- ⚡ **Feedback immédiat** avec correction
- 🏆 **Score cumulatif** sauvegardé
- 🎉 **Effets visuels** (confettis)

### 📊 Statistiques Détaillées
- 📝 **Mots appris** en temps réel
- 🔥 **Meilleure série** record
- 🏅 **Niveau de compétence** (4 niveaux)
- 💾 **Sauvegarde automatique** (localStorage)

### 📖 Dictionnaire Complet
- 📚 **3000+ mots** anglais-français
- 🔍 **Recherche instantanée**
- 🔗 **Navigation rapide** vers les flashcards
