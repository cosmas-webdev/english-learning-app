## 🎯 Pourquoi English Flashcards Pro ?

> *"La méthode la plus efficace pour apprendre l'anglais n'est pas de mémoriser des règles de grammaire, mais d'enrichir votre vocabulaire, un mot à la fois."*

**English Flashcards Pro** est bien plus qu'une simple application de cartes mémoire. C'est un **écosystème complet d'apprentissage** conçu pour vous faire passer de débutant à expert en anglais, que vous soyez étudiant, professionnel ou simplement passionné de langues.

## 🚀 Installation et Utilisation

### 📥 Méthode Rapide (recommandée)
1. **Téléchargez** le fichier ZIP du projet
2. **Décompressez** dans le dossier de votre choix
3. **Double-cliquez** sur `index.html`
4. **Commencez à apprendre !** 🎉

### 🖥️ Via Git (pour les développeurs)
```bash
# Cloner le dépôt
git clone https://github.com/cosmas-webdev/english-learning-app.git

# Accéder au dossier
cd english-learning-app

# Ouvrir dans le navigateur
start index.html
# Installer l'extension "Live Server" dans VS Code
# Clic droit sur index.html → "Open with Live Server"
