# English Flashcards App

Application d'apprentissage d'anglais avec flashcards interactives et quiz.

## 🛠️ Technologies
- HTML5
- Tailwind CSS (CDN)
- JavaScript
- Git/GitHub

## 🚀 Fonctionnalités
- 📝 Flashcards avec animation flip
- 🎯 Quiz de traduction
- 📊 Suivi de progression
- ⌨️ Raccourcis clavier (Espace, Flèche droite, Entrée)

## 📖 Utilisation
Ouvrir `index.html` dans un navigateur.
