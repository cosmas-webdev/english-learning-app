## 🎯 Pourquoi English Flashcards Pro ?

> *"La méthode la plus efficace pour apprendre une langue n'est pas de mémoriser des règles de grammaire, mais d'enrichir votre vocabulaire, un mot à la fois."*
>
> — **Principe de la répétition espacée**

**English Flashcards Pro** transcende la simple application de cartes mémoire. C'est un **écosystème complet d'apprentissage** conçu avec soin pour vous accompagner de **débutant à expert** en anglais, que vous soyez :

- 🎓 **Étudiant** préparant ses examens
- 💼 **Professionnel** souhaitant évoluer dans sa carrière
- ✈️ **Voyageur** désirant communiquer à l'étranger
- 🌍 **Passionné de langues** en quête d'enrichissement personnel

## ⌨️ Raccourcis Clavier

| Touche | Action | Contexte |
|:------:|--------|:--------:|
| <kbd>Espace</kbd> | Retourner la carte | 📝 Flashcards |
| <kbd>←</kbd> | Carte précédente | 📝 Flashcards |
| <kbd>→</kbd> | Carte suivante | 📝 Flashcards |
| <kbd>Entrée</kbd> | Valider la réponse | 🎯 Quiz |
| <kbd>1</kbd> | Onglet Cartes | 🌐 Global |
| <kbd>2</kbd> | Onglet Quiz | 🌐 Global |
| <kbd>3</kbd> | Onglet Statistiques | 🌐 Global |
| <kbd>4</kbd> | Onglet Dictionnaire | 🌐 Global |
| <kbd>Échap</kbd> | Fermer le menu mobile | 📱 Mobile |

## 🎨 Design & Architecture

### Principes de Design
- 🎯 **Minimalisme fonctionnel** : chaque élément a une utilité
- 🌓 **Dualité clair/sombre** : confort visuel en toutes conditions
- ✨ **Micro-interactions** : retours visuels pour chaque action
- 📱 **Mobile First** : conçu d'abord pour les petits écrans
- ♿ **Accessibilité** : navigation au clavier, labels ARIA
